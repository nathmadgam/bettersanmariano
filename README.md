# Better San Mariano

A community-run portal for **San Mariano, Isabela**: municipal officials, offices, services and public information in one place.

Better San Mariano is a volunteer project listed in the [BetterGov.ph LGU Directory](https://lgu.bettergov.ph/). It is **not** an official website of the Municipality of San Mariano.

## About San Mariano

San Mariano is a municipality in the province of Isabela in the Cagayan Valley region of the Philippines, about 37 km from the provincial capital Ilagan, with 36 barangays and a 2020 census population of 60,124. It is described as a gateway to the Northern Sierra Madre Natural Park and is known for community-based conservation of the Philippine crocodile.

## Run it locally

Requires Node.js 18 or newer.

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

Site content lives in `content/` (Markdown and YAML) and `src/data/`. See [CONTENT-MANAGEMENT.md](CONTENT-MANAGEMENT.md) for how to edit pages without touching code.
